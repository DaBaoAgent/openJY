# 短剧结构库（就医引流 · China Medical Journey）

> 来源：短剧爆款拆解 + 就医题材适配。供 lib/copybook.structure_brief 注入文案生成参考。

## 一、时间节拍（10s 竖屏口播）
1. 0.0–0.6s 留白起句（不抢字，起句留白固定 0.6s）。
2. 0.6–3.0s **钩子**：一句设问 / 一个反差 / 一个悬念，直接点名观众的顾虑
   （费用？语言？安全？等太久？）。禁止在此堆信息。
3. 3.0–7.0s **铺垫→转折**：先承认顾虑是真的，再给出一条具体、可验证的事实
   （医院层级 / 英文陪诊 / 先给估算 / 快通道）。
4. 7.0–9.5s **收口**：把卖点落到一个干净的动作或一句可信的话上，不喊口号。
5. 9.5–10s 自然收尾，不留硬 CTA 尾巴（平台侧 CTA 放文案/封面，不占口播）。

## 二、爽点类型（就医题材可用的四种）
- **纠偏打脸**：先立「中国医疗 = 落后/语言不通」的旧印象，再用现代医院画面与服务纠正。
- **流程顺滑**：把一整套麻烦（签证/接机/问诊/检查/病房）压缩成「有人全程安排好」。
- **费用透明**：把最大的不安（账单不清）变成「先给参考估算、医院出最终报价」的确定感。
- **身份代入**：外籍患者第一人称自述，用「我也怕过，直到……」建立可信度。

## 三、台词规则
- 一条连贯说完，中途不停顿（对齐产线语速档：es 更快、拉美语流；en 稍快）。
- 无标点、无阿拉伯数字（数字一律写成读法，如 "ten thousand dollars"）。
- 口语短句，一句一个意思；不堆形容词。
- **医疗红线**：不得承诺疗效/治愈，不得用绝对化用语（最好/第一/唯一/100%），不得写具体报价。

## 四、检查清单（出片前）
- [ ] 钩子在前 3 秒出现，且指向一个真实顾虑。
- [ ] 中段给出至少一条可验证的事实，而非形容词。
- [ ] 全片无疗效承诺、无绝对化用语、无具体报价。
- [ ] 台词单位数落在语速档预算内，一条连贯无停顿。
- [ ] 收口干净，不喊空口号。
